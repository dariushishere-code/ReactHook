# React Hooks Homework

Simple React app with two exercises using hooks.

## Features

### 1. User List CRUD
- Fetches users from https://jsonplaceholder.typicode.com/users
- Stores data in useState
- Add new user with name and email form
- Delete user with button

### 2. Image Gallery
- Fetches images from Lorem Picsum API (https://picsum.photos)
- Displays images in a responsive grid
- Load More button to fetch next set of 9 images
- Uses useState and useEffect

## How to run

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal.
